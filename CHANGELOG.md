# Changelog — APEX DRIVE

Har din ka ek chhota update. Naya entry sabse upar.

## 2026-11-21 — baseline
- Single-file build (`index.html`, ~914 KB) from `source/` — three.js r149 + fonts embedded
- 3 circuits (Costa Verde, Redrock Canyon, Neo Harbour) + Meridian City open world
- 6 procedural sports cars, grip-limited arcade handling (Easy/Normal/Pro), nitro, traffic, rivals, coins, checkpoint gates
- Touch controls: buttons / steering wheel / tilt, customisable size, sensitivity, handedness, opacity
- Fullscreen, garage with live 3D preview, results + star objectives, localStorage save
- Reproducible build: `python3 source/build.py`
